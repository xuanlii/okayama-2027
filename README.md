# 2027 年 2 月岡山五天四夜三代同遊自駕行程規劃

線上行程表（手機／電腦響應式導覽）：[https://xuanlii.github.io/okayama-2027/](https://xuanlii.github.io/okayama-2027/)

## 行程概要
- **日期**：2027/02/10（週三）– 2027/02/14（週日），五天四夜早去午回
- **同行成員**：4 位成人（含 2 位 60 歲長輩）＋ 1 位 10 個月大嬰兒
- **航班**：台灣虎航桃園（TPE）直飛岡山（OKJ）`IT214` / `IT215`
- **住宿**：岡山市北區西古松 3 房獨棟民宿連住 4 晚（附 2 個免費停車位）
- **租車**：TOYOTA Rent a Car 岡山機場店 `VOXY Hybrid`（W2 等級、配雪地輪胎與 1 座嬰兒安全座椅）

## 網頁功能
- **隱私加密鎖定**：訂位代號、民宿門牌與地圖連結、房東聯絡電話、同行者姓名、費用金額與確認信連結預設採前端加密遮罩保護，需於頁面輸入家族密碼解鎖後才顯示
- **電腦與手機雙平台自適應排版**：手機支援頂部橫向快跳膠囊列、單日切換標籤與獨立預訂資訊卡片
- **實景照片與歷史導覽圖鑑**：收錄倉敷美觀地區、倉敷常春藤廣場、三井 Outlet 倉敷、永旺夢樂城岡山、吉備津彥神社、農マル園芸 吉備路農園、備中國分寺、鷲羽山展望台與兒島牛仔褲街、岡山後樂園、岡山城及岡山神社的實景照與歷史背景
- **實用自駕與行前檢核**：提供預訂代號／日文地址／車用導航電話一鍵複製功能，以及儲存在裝置 `localStorage` 的行前檢核進度清單
